Independent implementation:
- Capture the native UILabel draw into one transparent image and apply a solid
  black/white source-in fill, then draw it back at the original rectangle.
- Retain native font/layout/truncation and alpha, including attributed white
  foreground runs. No textColor/attributedText/scene settings are modified.
- Scene session role SystemAperture, the dedicated island windows, or an aperture
  ancestor define scope, including native offscreen aperture content. Normal app labels bypass.
- The host publishes a small versioned appearance/state value via Darwin notify.
  Content services consume that value rather than their own forced-Dark traits
  or sandbox-specific preference reads. Invalid/missing/disabled state is native.
- Host activation follows actual attached glass; theme changes invalidate only
  tracked labels. No callback touches UIScreen in backboardd.
- Plain bitmap bounds/scale are checked before allocation. Nested UIKit draw
  aliases call their originals without another capture.
- Method return types are checked before hooking. Real iOS 17.4 reports CGRect
  for _drawTextInRect: but void for _drawFullMarqueeTextInRect:. Support both
  known return shapes for the latter rather than trusting decompiler output.
- This recolors label ink, including inline colored glyphs rasterized by UILabel.
  It does not intercept UIImageView artwork or arbitrary custom/SwiftUI canvases.
