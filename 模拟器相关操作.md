## 查找Files中的我的iPhone地址

### 1. 找到Booted的模拟器的DeviceID
```
/Users/hades/Library/Developer/CoreSimulator/Devices/<DEVICE_ID>/data/Containers/Shared/AppGroup/
```

### 2. 在模拟器中的我的iPhone中新建一个文件夹123321

### 3. 在这个目录 查找 “File Provider Storage”
```
find . -name "123321"
```

### 4. 找到的就是了
