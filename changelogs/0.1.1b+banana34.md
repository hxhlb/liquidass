# 0.1.1b+banana34

测试版 / Test build

- 接入上游 AssistiveTouch、音量 HUD、铃声提示玻璃，以及键盘、菜单、TabBar 和 RTL 等界面更新。
- 时钟新增“原生修改／自定义层”，默认保持原生修改；共用字体和日期设置。
- Enhanced 新增“当前方式／系统模糊层”对照，默认当前方式；Classic 下不可选，保留上次选择。
- 应用排除列表接入 AltList，保留旧进程名配置；新增 AltList 依赖。
- 保留 Banana 的 iOS 15–18 兼容修复、图标／小组件修复和开关启用状态同步。
- 安装脚本不再自动结束 backboardd；安装完成后请手动重启用户空间。
- 本轮用于真机对照；两种时钟、模糊方式及新增界面的效果和性能尚待验证。

- Integrates upstream AssistiveTouch, volume/ringer HUD glass and keyboard, menu, tab bar and RTL updates.
- Adds Native modification / Custom layer clock modes, retaining the current mode by default and sharing font/date controls.
- Adds Current method / System blur layer comparison in Enhanced. Classic disables the option without clearing the saved choice.
- Adds AltList application exclusions while preserving legacy process-name entries; AltList is now a dependency.
- Retains Banana iOS 15–18 compatibility, icon/widget fixes and asynchronous switch enable-state synchronization.
- The installer no longer terminates backboardd; restart userspace manually after installation.
- Test build: clock modes, blur methods and new surfaces still need on-device visual and performance validation.
