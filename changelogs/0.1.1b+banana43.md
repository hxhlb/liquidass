# 0.1.1b+banana43

测试版 / Test build

- 同版本默认值更新：灵动岛浅色黑色约 5%（RGBA 末位 0D），模糊参数 2；横幅浅色保持白色、不透明度 20%。两套参数表同步，已有用户设置优先。
- Same-version defaults update: island Light tint is black at approximately 5% opacity, blur parameter 2; banner Light tint remains white at 20%. Both profiles share these defaults; saved user values take precedence.

- RootHide／Rootless 渲染端统一使用与设置页一致的偏好服务，移除 RootHide 对固定 plist 路径的依赖。
- 偏好同步或读取失败时保留上次有效材质参数；首次启动失败时仍初始化完整默认参数。
- 导出日志增加渲染端读取结果、运行／设置渲染器模式及灵动岛实际加载的 Light／Dark RGBA，不依赖 backboardd 能否直接写入共享日志文件。
- 全部玻璃材质共用颜色解析，统一支持 RGB／RGBA；修正时钟下拉层对 6 位 RGB 的误读。
- 时钟新增“自适应色调”开关：关闭后使用独立 Light／Dark 色调，避免被通知材质或自适应颜色覆盖。Classic 默认开启、Enhanced 默认关闭，分别保存并支持三种语言。
- 保留 banana42 灵动岛文字逻辑；不加入按钮圆形玻璃。
- 安装不自动重启；由用户重载进程以加载新版本。真机色调效果待验收，iOS 16 GainMap 启动崩溃未包含修复。

- Both jailbreak builds read renderer preferences through the same CFPreferences service as Settings; RootHide no longer depends on a hardcoded plist path.
- Failed synchronization/reads retain the last applied parameters, with complete defaults available on first launch.
- Exported UI logs now include renderer-side read status, running/requested profiles and loaded island Light/Dark RGBA through Darwin notification state.
- Shares RGB/RGBA parsing across Settings, renderer and clock pull tint; fixes six-digit clock color decoding.
- Adds a per-renderer adaptive clock tint toggle (Classic on, Enhanced off by default). Custom clock colors no longer inherit notification tint or get overwritten by adaptive color.
- Keeps banana42 island text behavior; no circular button treatment or automatic process restart.
- Actual device tint behavior requires validation. This does not fix the separate iOS 16 GainMap startup crash.
