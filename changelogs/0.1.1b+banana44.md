# 0.1.1b+banana44

测试版 / Test build

- 调整 iOS 16 灵动岛 GainMap 处理，不再创建屏幕外原生保活层；iOS 17/18 保持原路径。针对卡启动问题的候选修复，仍需 iOS 16.3 真机验收。
- 标签栏排除名单支持热更新，补齐退出效果时的外观、按钮位置与待执行动画恢复。
- 系统照片小组件保留原生背景与快照；宿主与独立渲染进程共同保护，并保留旧系统分支。
- 滤镜暂未准备好时增加有限重试；离窗、关闭效果或对象释放后不继续重试。
- 不加入渐变色、导航按钮改造或实时活动去黑底。安装不会自动重启。

- Changes the iOS 16 Island gain-map path to omit the offscreen native keeper while preserving iOS 17/18 behavior. This startup-hang candidate still requires iOS 16.3 device validation.
- Updates tab-bar exclusions live and restores appearance, button geometry and pending interaction state when excluded.
- Preserves native Photos widget backgrounds and snapshots in both host and renderer paths, retaining legacy OS branches.
- Adds bounded retries for unavailable filters, cancelled on detach, disable or deallocation.
- No gradient text, navigation-button redesign, activity background clearing or automatic restart.
