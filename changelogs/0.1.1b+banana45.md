# 0.1.1b+banana45

测试版 / Test build

- 修复 banana44 在标签栏宿主布局回调中重复请求布局的问题，避免 Sileo 等应用持续布局；仍需真机确认启动与交互恢复。
- 保留标签栏排除名单热更新，仅在设置变更时主动请求重新布局。
- 保留 banana44 的 iOS 16 灵动岛修复。安装不会自动重启。

- Fixes repeated layout requests from tab-bar host layout callbacks introduced in banana44, preventing a layout feedback loop in apps such as Sileo. Device confirmation of launch and interaction is still required.
- Preserves live tab-bar exclusions, requesting a fresh layout only on preference changes.
- Retains the banana44 iOS 16 Dynamic Island fix. Installation does not restart processes automatically.
