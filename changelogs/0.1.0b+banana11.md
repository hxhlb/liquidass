# 0.1.0b+banana11

This is the first maintained Banana fork release based on upstream 0.1.0b.

## live preferences

- removed the redundant Apply action and committed preference changes automatically
- unified preference access through CFPreferences across Rootless and RootHide
- added a transient confirmation when settings are applied live
- made the global switch strictly restore stock UI when disabled

## icon highlights

- added lightweight adaptive highlights for Home Screen and Dock app icons
- replaced the experimental EX name with Icon Highlights
- aligned the visible light direction with LiquidAss folder highlights
- added a narrow specular core, soft optical bloom and color-preserving blend modes
- adapted icon detection across screen sizes and SpringBoard view hierarchies on iOS 17 and iOS 18
- kept App Library pods on their existing upstream rendering path

## folders and widgets

- restored opened-folder glass after the iOS 18 opening transition replaces or reorders its material view
- improved stock material cleanup and final filter rebinding
- added explicit RWB controls for widgets and restored widget state when disabled

## package and compatibility

- changed the fork package id to iya.iapple.liquidass while preserving the upstream preference domain
- added Conflicts, Replaces and Provides metadata for dylv.liquidass
- preserved existing upstream preferences during migration
- fixed maintainer scripts to resolve sleep and killall through the apt/dpkg environment on Rootless and RootHide
- restart backboardd after installation and from the settings restart action
- added complete English, Spanish, Polish, Russian, Ukrainian, Vietnamese, Simplified Chinese and Traditional Chinese localization coverage
- credited dylv & banana in package and settings metadata
