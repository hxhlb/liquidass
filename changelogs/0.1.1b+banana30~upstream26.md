# 0.1.1b+banana30~upstream26

Rootless clock resources and iOS 18 renderer compatibility.

- locates the variable clock font through the Rootless resource path; retains the existing RootHide path
- reads Rootless backend preferences through CFPreferences, matching the settings UI
- recognizes the Vec2 store emitted by iOS 18.5 in Gaussian edge-info detection
- adds an iOS 18 render wrapper that preserves both Shape pointers and the output pointer
- retains the older iOS 14 and iOS 15–17 render signatures
- keeps native alert backgrounds when the client cannot attach its glass filter
- native callback-forwarding and scanner regressions passed; final GPU output requires device testing
