# 0.1.1b+banana35

测试版 / Test build

- 修复辅助触控在首次布局前尺寸为零时，生成光晕图片触发 iOS 17 绘图断言、导致辅助触控进程崩溃的问题；获得有效尺寸后再生成光晕。
- 为没有独立 MaterialWrapper 的音量 HUD 接入实际的 SBElasticSliderView 层级；保留音量填充和图标，滤镜就绪后才隐藏原背景，关闭时恢复。
- 保留时钟双模式、Enhanced 模糊对照和现有 Banana 修复；安装脚本不自动结束 backboardd，安装完成后请手动重启用户空间。
- 原因已通过 iOS 17.3.1 真机崩溃栈及图层捕获确认；修正版视觉效果仍待安装验证。

- Prevents AssistiveTouch crashing on iOS 17 when glow generation receives zero-sized initial bounds; creates the glow once valid geometry is available.
- Adds the observed SBElasticSliderView HUD path on systems without the separate material wrapper, preserving volume fill/glyphs and restoring stock backgrounds on disable.
- Retains dual clock modes and Enhanced blur comparison. Installation does not terminate backboardd; restart userspace manually afterward.
- Causes confirmed from iOS 17.3.1 crash symbols and live hierarchy capture; fixed-package visual validation is pending.
