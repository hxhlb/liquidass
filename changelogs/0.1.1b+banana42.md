# 0.1.1b+banana42

测试版 / Test build

- 灵动岛文字采用统一双色绘制：Light 黑字、Dark 白字，无需新增设置。
- 同时处理普通文字、富文本及滚动文字，保留原布局、字体和透明度；不对专辑封面做反色。
- 由 SpringBoard 同步玻璃启用状态和主题，避免内容服务自身的深色配置影响判断。
- iOS 17.4 真实 UIKit 像素检查及跨进程主题传递检查通过；音乐、录屏真机效果仍需验收。
- 安装脚本不重启任何进程，由用户手动操作。
- 此包不宣称修复 iOS 16 的 GainMap 崩溃循环；该问题继续单独排查。

- Uses one text drawing path for black ink in Light mode and white ink in Dark mode, with no new setting.
- Covers plain, attributed and marquee UILabel drawing while retaining native layout, fonts and alpha; does not invert album artwork.
- SpringBoard supplies the active-glass state and theme across processes.
- Real UIKit pixel and cross-process notification checks pass on iOS 17.4; actual music/recording content still requires device acceptance.
- Installation does not restart processes. This is not a claimed fix for the separate iOS 16 GainMap crash loop.
