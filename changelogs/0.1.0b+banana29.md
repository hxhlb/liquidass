# 0.1.0b+banana29

## icons and folders

- refined the clear icon renderer with stronger subject separation, live glass depth, and balanced Light/Dark appearances
- added an optional IconServices provider-level path so clear icons can also appear outside SpringBoard
- improved unopened folder mini-icons and fixed legacy iOS 15-17 folder compatibility

## Dynamic Island and Dock

- added Liquid Glass styling for Dynamic Island with stable expanded and collapsed states
- synchronized the outer glass rim with idle visibility while preserving the system transition path
- improved the iPad-style Dock App Library button and removed its white background flash during the App Library closing animation

## widgets and stability

- added optional widget background removal while keeping glass edges independently configurable
- added legacy iOS 15/16 widget-host handling and the required System UI restart guidance
- fixed asynchronous view-lifetime crashes in icon and folder refresh paths
