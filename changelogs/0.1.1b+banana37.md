# 0.1.1b+banana37

测试版 / Test build

- Classic 与 Enhanced 分别保存渲染参数，修改或重置一边的材质参数不会覆盖另一边；导入导出可同时保留两组配置。
- 旧共享材质配置保留给 Classic；Enhanced 首次使用独立的上游默认值，不再读取旧共享材质值或做新旧引擎间的六倍换算。
- Enhanced 按上游使用固定边缘宽度，默认采用系统模糊层；Classic 保留原比例和旧格式兼容行为。
- 修正 Enhanced 辅助触控厚度被错误放大的问题；质量、高光和时钟刷新率也随引擎分别保存。
- 总开关、表面启用、时钟字体／显示模式和图标模式继续共用。
- 合入滤镜初始化时序调整，重试时避免重复挂钩并复用已解析槽位；保留原有崩溃保护。
- 安装后请手动重启用户空间；切换引擎仍需完成重启。安装脚本不结束 backboardd，发热和耗电变化待真机验证。

- Separates Classic and Enhanced rendering settings, including independent edits and surface resets; preset export/import retains both groups.
- Keeps legacy shared material settings for Classic. Enhanced starts from raw upstream defaults without legacy fallback or cross-engine sixfold scaling.
- Enhanced uses upstream point widths and defaults to system blur. Classic retains proportional edges and legacy preset compatibility.
- Corrects amplified AssistiveTouch thickness in Enhanced. Quality, highlights and clock FPS are saved per engine.
- Master/surface enable flags, clock fonts/rendering mode and icon modes remain shared.
- Updates filter initialization ordering with one-time hooks and cached retry slots while preserving crash protection.
- Restart userspace manually after installation and after changing engines. The installer does not terminate backboardd; heat/power impact still needs device testing.
