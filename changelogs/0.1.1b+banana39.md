# 0.1.1b+banana39

测试版 / Test build

- 灵动岛内容跟随系统浅／深色外观，修正透明玻璃在浅色模式下仍使用深色外观白字的问题。
- 适配内容所在的 UIKit 进程，保留系统字体大小、对比度等其他 traits；不对封面或整块内容做反色。
- 关闭功能、内容替换或离开窗口时恢复原始外观。
- 主机回归通过；系统内容、第三方实时活动和写死文字颜色的内容仍需真机验收。
- 安装后请手动重启用户空间，使内容进程载入更新；安装脚本不结束 backboardd。

- Makes Dynamic Island content follow system Light/Dark appearance for legibility on transparent glass.
- Applies within the content's UIKit process, preserving Dynamic Type and other traits without inverting artwork or the whole content surface.
- Restores native appearance on disable, replacement, and detachment.
- Host regressions pass; system content, third-party Live Activities, and explicitly fixed text colors still require device acceptance.
- Restart userspace manually after installation to reload content processes. The installer does not terminate backboardd.
