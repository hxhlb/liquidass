# 0.1.1b+banana46

测试版 / Test build

- 新增“排除照片小组件”开关，默认关闭；开启后保留系统照片小组件的原始背景与快照。
- 修改该选项后请手动重启系统界面。保留 banana45 的标签栏与 iOS 16 灵动岛修复。
- 本包用于对照验证小组件黑底与玻璃显示问题，尚未确认解决该问题；安装不会自动重启。

- Adds Exclude Photos Widgets, off by default. Enable it to preserve native backgrounds and snapshots in Apple's Photos widgets.
- Restart System UI manually after changing this option. Retains the banana45 tab-bar and iOS 16 Dynamic Island fixes.
- This build is for comparing widget background and glass behavior; resolution of the reported black background is not yet confirmed. Installation does not restart processes automatically.
